# OpenCart E-Commerce Application - End-to-End Manual Testing Portfolio

## 🚀 Project Overview
This repository showcases a comprehensive, structured manual testing portfolio executed on the live open-source OpenCart E-Commerce Web Application. The objective of this project is to implement robust Quality Assurance (QA) methodologies, validating functional requirements, user journeys, and edge boundaries.

## 🛠️ Tech Stack & QA Tools
*   Methodology: Agile-Scrum, Software Testing Life Cycle (STLC)
*   Test Management: Microsoft Excel / Google Sheets (Matrix Design)
*   Defect Tracking Simulation: Jira Workflow Alignment
*   Platform Environments: Google Chrome, Mozilla Firefox (Cross-Browser)

## 🎯 Key Achievements & Coverage
*   Designed and mapped functional, boundary, and negative test cases.
*   Identified and systematically documented critical application edge-case defects.
